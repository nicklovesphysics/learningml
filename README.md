# learningml
My repository for learning ML and all associated projects!

So far, I've made:

1. a linear regression from scratch
2. a (only got it to work once, never validated) homemade neural network with NumPy

And I want to make:
    - Decision trees/random forests
    - RNNs
    - Neural Network with PyTorch
    - LSTM model
    - Time Series analysis project
    - Logistic Regression

The neural network was an unfortunate failure after hours and hours of bug fixing. I would have had to go back into the classes I wrote and redo the architecture, which I unfortunately do not have time for with classes starting up. I learned lots about the structure and mathematics behind neural networks, though, and for attempting to build one on my own with no tutorials outside of basic layer/forward propagation structure, I consider this loss a success. 

After I make something from scratch (like my linear regression) and understand the fundamental mathematics and concepts underlying the functionality, I let myself learn specialized libraries to code them more efficiently (scikit-learn LinearRegression in this case).
